# Generated artifacts

This directory contains runtime and reproducible outputs and is ignored by
Git except for this file.

- `checkpoints/`: accepted-iteration LumOpt parameters and watchdog logs.
- `plots/`: generated geometry and paper-reconstruction figures.
- `runtime_scripts/`: generated Lumerical scripts.
- `simulation_outputs/`: solver projects, exported data, and diagnostics.
- `cache/`: preserved Python bytecode and local cache state.
