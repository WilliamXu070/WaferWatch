# Planned FDE/EME pipeline

This directory is reserved for the current-platform mode-based optimizer:

1. Build bent-waveguide FDE modes versus radius and propagation angle.
2. Track TE, TM, higher-order, and useful leaky modes by overlap.
3. Form multimode interface scattering matrices.
4. Cascade generalized-Euler segments and optimize transmission.
5. Validate shortlisted curves with the active 3D FDTD workflow.

No paper-platform dimensions should be substituted for
`configs/current_lnoi.py`.
